About

事業のそばに、
いつもいる存在に。

はじめまして、Ryo Yamashiro です。20代後半、副業としてWeb制作・開発を行っています。SEとして3年、そのうち1年はNext.jsを使った開発を経験しています。HTML / CSS / JavaScript に加え、PHP・Laravel・WordPressも扱い、既存サイトの改修から新規制作まで対応します。

大切にしているのは「即レス」と「ちゃんと話すこと」。要件が曖昧なまま進めるのではなく、何を優先すべきか一緒に整理しながら、リリース日に確実に間に合わせる進め方を心がけています。技術だけでなく、コミュニケーションでお客様の不安をゼロにすることが自分の強みです。

今のサイトを、これからも運用しやすく。

PHPのバージョンやWordPressのプラグインの脆弱性対応・更新管理が気になる方へ。Next.jsとヘッドレスCMSを組み合わせた構成への移行もご相談いただけます。コンテンツを管理するCMSと、画面を表示する仕組みを分ける構成です。現在の運用や更新頻度を伺い、既存サイトの改修も含めて、ご要望に合う方法を一緒に検討します。

WordPress Web制作 BUDDYB Personal Gym

BUDDYB Personal Gym

沖縄・名護のパーソナルジム｜コーポレートサイト新規制作

サイトを見る
buddyb-personal-gym.com

「ジムのオープンまで時間がない」という状況からスタート。構想段階からヒアリングを重ね、ブランドコンセプトの言語化・機能の優先度整理を行いながら、リリースまで伴走しました。リリース時には画面共有でWebサーバーやドメインの仕組みをゼロから説明し、サーバー費用やドメイン費用の意味を納得したうえで運用をスタートしてもらえるよう2時間かけてサポート。「何から話せばいいかわからない」という状態でも、一緒に整理するところから始められます。

Process

01
ヒアリング・構想整理

言語化できていない想いも、対話を通じて整理します。

02
要件定義・優先度決め

納期・予算に合わせて機能をフェーズ分け。

03
実装・テスト

こまめにスクショや画面録画を送り、完成イメージを都度共有。遅延時は正直に報告・優先度再調整・第二フェーズ打診。

04
納品・サポート

納品時はサーバー・ドメインの仕組みを画面共有でわかりやすく説明。「なぜこの費用が必要か」を納得したうえで運用スタート。

お客様の声
