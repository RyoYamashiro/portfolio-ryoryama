# STELLA（白基調 /gym）のCMS設定

NAGIの接続に使用しているmicroCMSサービスとAPIキーを共用し、STELLA用のオブジェクトAPIを1つ追加します。NAGIの既存API・スキーマを上書きしないでください。

## 1. APIを追加する

- API名：白基調のジムサイト
- エンドポイント：`gym`
- APIの型：**オブジェクト形式**
- スキーマ：[gym-schema.json](microcms/gym-schema.json) をファイルインポート

API数の上限で追加できない場合は、既存APIを削除せず、別サービスの利用や契約内容を確認してください。この実装は両テンプレートが同じサービスにある構成です。実アカウントへのスキーマ取り込みは未検証です。

## 2. ダミーを入力して公開する

基本情報・見出しには初期値を用意しています。必須項目に加え、料金プランとトレーナーをそれぞれ1件作成します。FAQは0件でも構いません。

| 項目 | 動作確認用の入力例 |
| --- | --- |
| 料金プラン → プラン名 | スタンダードプラン |
| 料金プラン → 月額料金 | 33000 |
| 料金プラン → プランの説明 | 月4回・1回60分。税込価格です。 |
| トレーナー → 名前 | デモトレーナー |
| トレーナー → 紹介文 | 動作確認用の仮プロフィールです。 |

写真は未設定ならデモ写真を使います。本番では実店舗・本人の写真と正しい情報へ変更してください。[全項目の入力例](microcms/gym-content-example.json) は参照用で、スキーマとして取り込むファイルではありません。

入力後は下書き保存だけでなく「公開」してください。既存のAPIキー設定で、新しい `gym` APIへのGET権限も確認してください。キーの新規作成は不要です。

## 3. 接続を有効にする

既存の `.env.local` に以下の1行を**追記**します。サービスID・APIキー・NAGIの `MICROCMS_GYM_ENDPOINT=gym-premium` はそのまま残します。

```dotenv
MICROCMS_STELLA_ENDPOINT=gym
```

未設定・空欄ならSTELLAはデモ表示です。設定後に通信失敗・未公開・入力不備が起きた場合は、デモ料金に戻さずエラーを表示します。

```sh
npm run cms:check:gym
```

「接続OK」になったら既存の開発サーバーをCtrl+Cで停止し、同じポートで起動し直します。

```sh
npm run dev -- --port 3010
```

<http://127.0.0.1:3010/gym> を開いて確認します。NAGIは引き続き `/gym-premium`、ルート `/` は `/gym` に転送します。

## 動作確認

1. ジム名とトップの見出しを変更・公開し、サイトを再読み込みする。
2. 料金が33,000円、プランとトレーナーが各1件になっていることを確認する。
3. トップ写真・プラン写真・トレーナー写真を差し替えて確認する。
4. FAQを追加・並べ替え・削除し、表示も追従することを確認する。
5. 予約URLに自分の予約ページのHTTPS URLを設定し、下部の予約ボタンから移動できることを確認する。
6. SEOタイトル・説明の変更を公開し、ページのtitle・descriptionに反映されることを確認する。
7. 公開せず下書き保存した変更がサイトに出ないこと、NAGIの内容が変わらないことを確認する。

## 編集対象と実装

CMS対象はジム名・ロゴ下の説明・電話・受付時間・トップ画像と文章・予約エリアの見出し・予約URL・SEO・料金プラン（1〜3件）・トレーナー（1〜3人）・FAQ（0〜30件）。日本語の項目名と説明付きです。

特徴セクション（ジム名以外）、利用の流れ、口コミ、ブログ、装飾写真、固定ボタン文言、テーマ色は引き続きテンプレートのデモです。ブログ管理・独自admin・簡単モードは今回の対象外です。実店舗の公開前には仮情報・画像・無料相談などの表現とサービス条件を確認してください。デモとしてnoindexを指定しており、公開設定の完成は意味しません。

- `cms/microcms/client.js`：共通の公開データ取得。キーはサーバーだけで扱う。
- `cms/microcms/fields.js`：共通の文字列・HTTPS予約URL・microCMS画像URLの検証。
- `cms/microcms/stella.js`：STELLAの有効化・取得。同じリクエスト内でメタ情報と本文を共有。
- `cms/microcms/normalize-stella.js`：料金・件数・項目の検証と表示用データへの変換。
- `app/gym/page.jsx`：取得した情報を各部品に渡す。
- `content/gym/`：未接続時のデモデータ。
- `scripts/create-stella-schema.mjs`：日本語スキーマと入力例の生成元。再生成は `npm run cms:schema:gym`。

自動テストは模擬APIでHTML・SEO・画像URL・料金・予約リンク・更新・エラー・NAGIとの分離を検証します。実際の管理画面での操作と写真の視覚確認は別途必要です。
